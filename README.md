# SovereignFi

Official Android release builds of SovereignFi, a personal finance app that keeps your data on your device.

## Download

**[Download the latest version](https://github.com/sovereign-fintracker/SovereignFi-releases/releases/latest)**

Open that page, scroll to **Assets**, and tap the file ending in `.apk`
(for example `SovereignFi-beta-1.0-1.apk`).

All versions: [Releases](https://github.com/sovereign-fintracker/SovereignFi-releases/releases)

## Install

1. Download the `.apk` on your Android phone.
2. Open it. If Android asks, allow your browser or file manager to **install unknown apps**.
3. Tap **Install**.

## Updates

When a newer version is published, the app shows an **Update available** sheet when you open it.
Tap **Update**, then **Install** on the Android prompt. Updates install over your current app and keep your data.

## Beta notice

This is an early beta. Expect rough edges while bugs are being fixed.

- Cloud sync is a Pro feature. Free accounts keep everything on the device.
- To read statements with Gemini, add your own free Gemini API key in **Smart Features**.

Requires Android 7.0 or newer.
